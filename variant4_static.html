Вариант 4 — Уравнение: X / 8 = 6

Исходное уравнение: X/8=6

Оператор: деление (/)

Расположение неизвестной X: левая часть, первый операнд

Шаги решения: X = 6 * 8

Значение переменной: X = 48

Блок-схема алгоритма работы программы

Овал — начало / конец

Параллелограмм — ввод / вывод данных

Прямоугольник — действие / вычисление

Ромб — проверка условия (ветвление)
